Configuration Options

All progress components are configured using the data-bs-config attribute with JSON configuration:

  • strokeWidth: Sets the stroke width in pixels for circular progress bars
  • duration: Animation duration in milliseconds (default: 1500)
  • delay: Delay before animation starts in milliseconds (default: 0)
  • animation: Whether to animate the progress (default: true)
  • animateInViewport: Only animate when the element enters the viewport (default: true)

This component also respects the user's prefers-reduced-motion browser setting. When enabled, animations will be disabled automatically for users who have indicated they prefer reduced motion in their system settings.
